# LalaGi Dimsum — Website Guidelines

## Project Overview
Official brand website and high-converting landing page for **LalaGi Dimsum** (Jagakarsa, Jakarta Selatan).

## Tech Stack
- **Framework:** Next.js 16 (App Router, React 19, TypeScript strict)
- **UI & Icons:** Phosphor Icons (`@phosphor-icons/react`), Iconify (`@iconify/react`), Tailwind CSS v4 with OKLCH design tokens
- **Typography:** Mochiy Pop One (Headlines & Display), Plus Jakarta Sans (Body & UI)
- **Deployment:** Vercel

## Commands
- `npm run dev` — Start dev server
- `npm run build` — Production build
- `npm run lint` — ESLint check
- `npm run typecheck` — TypeScript check
- `npm run check` — Run lint + typecheck + build

## Code Style & Principles
- TypeScript strict mode, no `any`
- Mobile-first, editorial food aesthetics
- Real brand photography, certified Halal MUI No. ID31110016921890424
- Warm food palette: `#FFF9F2` (cream bg), `#ED7772` (coral primary), `#321D16` (deep cocoa text)
