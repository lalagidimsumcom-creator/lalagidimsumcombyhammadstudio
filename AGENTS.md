# LalaGi Dimsum — Website Guidelines

## Project Overview

Official brand website and high-converting landing page for **LalaGi Dimsum** in Jagakarsa, South Jakarta.

## Tech Stack

- **Framework:** Next.js 16, App Router, React 19, strict TypeScript
- **Styling:** Tailwind CSS v4 with project design tokens
- **Icons:** Phosphor Icons (`@phosphor-icons/react`)
- **Typography:** Cinzel for display text; Arial for body and UI until the final brand font is selected
- **Deployment:** Vercel

## Commands

- `npm run dev` — Start the development server
- `npm run build` — Create a production build
- `npm run lint` — Run ESLint
- `npm run typecheck` — Run the TypeScript compiler without emitting files
- `npm run check` — Run lint, typecheck, and build

## Code Style & Principles

- Keep TypeScript strict and avoid `any`.
- Build mobile-first, accessible interfaces with an editorial food aesthetic.
- Use real LalaGi brand photography and accurate business information.
- Preserve the quiet-premium palette: navy `#17343D`, dark navy `#0E2831`, ivory `#F7F3EC`, white `#FFFCF7`, and gold `#B69A63`.
- Keep ordering flows clear and route calls to action through the shared WhatsApp helper.
- Display halal certification number `ID31110016921890424` accurately.
